# book-forge フェーズ0〜3 運用手順（対話パート）

進行は `project.json` を `scripts/pj.py` で読み書きしながら、ターン制で進める。各フェーズはゲート（`pj.py check <phase>`）を通るまで次に進めない。

初回：`python3 scripts/pj.py init <projectdir>` で空の project.json を作る。

---

## 🅿0 intake（要件ヒアリング）
**目的**：`meta` を埋める。**まとめて最大3〜5問**、選択式を優先し疲れさせない。

**聞くこと（1メッセージで提示）**
1. **本の種類**：実用書／エッセイ・自伝／専門書・技術書／小論文・レポート／ビジネス書／その他
2. **体裁・判型**：book(書籍)＋A5/B5/四六 か、essay(小論文)＋A4
3. **想定読者**（自由記述：誰が・前提知識）
4. **狙い**（自由記述：読後に何ができる/わかる。1文で言えないなら1問だけ深掘り）
5. **分量とトーン**：目標文字数の目安（例 実用書6万字/新書10万字/小論文4千字）＋トーン(やさしい/硬め/軽妙)
- 仮タイトルは任意（後で決めてよい）。

**記録**：`pj.py set <pj> meta.種類 "…"`／`meta.体裁`／`meta.判型`／`meta.読者`／`meta.狙い`／`meta.目標文字数 60000`／`meta.トーン` など。
**ゲート**：`pj.py check <pj> intake` が OK（必須メタ充足）→ `pj.py state <pj> research`。

---

## 🅿1 research（資料収集）
**目的**：主題・主張を支える出典を `research[]` に集める。
**やり方**：metaから検索クエリを作る → web_search/web_fetch → **要点＋数値をURLで裏取り**。広い調査はサブエージェント並列。
**ルール**：捏造厳禁。**URL＋参照日を必ず記録**。エッセイ・自伝など種類が体験主体なら調査は軽め。
**記録**：`pj.py add-research <pj> --出典 "…" --url "https://…" --要点 "…" --裏取り true --参照日 2026-08-19`
**ゲート**：`pj.py check <pj> research`（URL付き裾取り済みが要件。体験主体の種類は0でも可）→ 利用者に**資料サマリを提示して確認** → `state=interview`。

---

## 🅿2 interview（インタビュー）★独自性の源
**目的**：著者しか知らないこと（原体験・具体場面・独自ノウハウ・主張と反論）を引き出す。
**やり方**：質問は①metaの狙い ②researchの空白 ③種類別の定石、から生成。少数ずつ・双方向（著者→AIの質問にも答える）。

**種類別 質問バンク**
- エッセイ/自伝：忘れられない場面、そのときの感情、固有名詞・数字、転機、読者に一番伝えたい一言
- 実用書：読者が最初につまずく所、自分の実務経験、他書と違う独自手順、失敗談
- 主張型(小論文/評論)：主張、想定反論、最も強い根拠、譲れない一線、反対意見への応答
- 専門書/技術書：対象読者の前提、扱う範囲と扱わない範囲、実例/コード、落とし穴

**記録**：`pj.py add-interview <pj> --q "…" --a "…"`（著者の回答をそのまま素材に）。著者が出典を挙げたら add-research。
**ゲート**：独自性ある目次が書ける材料が揃い、「他に伝えたいことは？」を確認 → `pj.py check <pj> interview` OK → `state=outline`。

---

## 🅿3 outline（目次作成）
**目的**：meta＋research＋interview を統合し、**章・節＋目標字数＋各章1行のメッセージ見出し**を作る（合計字数≒meta目標）。
- 見出しは「背景」でなく**結論を含むメッセージ**（natural-japanese準拠）。
**提示**：読める目次として利用者に見せる。
**記録**：`pj.py set-outline <pj> '[{"章":"…","節":["…"],"目標字数":8000,"メッセージ":"…","状態":"draft"}, …]'`
**ゲート（重要）**：**著者が承認するまで本文を書かない**。承認されたら `pj.py approve <pj>`（approved=true・state=drafting）→ フェーズ4へ。

---

## 環境アダプタ
- Claude Code / OpenClaw：本手順＋`scripts/pj.py`をbashで実行。調査はweb検索/サブエージェント。
- ChatGPT：本手順を指示に、`pj.py`をコード実行で再現。調査はブラウジング、対話はチャット。**入出力は同じ project.json**。

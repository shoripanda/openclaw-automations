# book-forge 失敗ルート台帳

## 執筆・体裁ルール（必須）
- **利用者が指定した目標字数は必ず満たす**（大きく下回らない）。不足したら加筆して再ビルドする。字数はテキスト抽出で実測し、目標に届くまで繰り返す。
- **無意味な太字を付けない**。太字は「文中の核心1箇所」だけ（natural-japanese準拠）。日付・数字・固有名詞を機械的に太字化しない。
- **内容に関連する図・画像を入れる**（年表・概念図・データ図など）。図は下記の図表ルール（出典・可読性・サイズ）を満たすこと。
- **ノンブル（ページ番号）は下部・中央**に置く。柱（ランニングヘッダー）は基本なし。実装：LaTeXで `\pagestyle{plain}`（pandocなら `-V 'header-includes=\pagestyle{plain}'`）。build.sh に既定で反映済み。
- **図・画像のキャプション（説明文）は本文より小さい文字にする**。本文と同サイズだと「本文の続きか説明か」が判別できない。実装：`\usepackage{caption}` ＋ `\captionsetup{font=footnotesize,labelfont=bf}`（本文9ptなら約7pt）。build.sh の `_style.tex` に既定で反映済み。
- **語彙・固有名詞の表記を全体で統一する（表記ゆれ禁止）**。同じ対象は一つの表記に固定：製品・モデル名は正式表記（例：`Claude Code`／`Claude 3.7 Sonnet`／`Claude Opus 4.8`／`CurioLang`／`OpenClaw`／`ChatGPT`／`Anthropic`）。本文カタカナ（クロード…）と参考文献の英語（Claude…）を混在させない。初出の読みガナ（`CurioLang（キュリオラング）`）は補助なのでOK。実装：ビルド前に `grep -noE "対象語のゆれ候補" manuscript.md | uniq -c` で全変種を洗い出し、一表記へ寄せてから組版する。
- **1ページの文字数（密度）は可変**。大見出しや図が大きいと字数が減る＝判型のせいではなく設定。既定で見出しを詰め（titlesec）、図は幅指定（{width=…}）。密度は build.sh の環境変数 `FONTSIZE`／`MARGIN`（余白mm）／`LINESPREAD`（行間）で調整。プリセット：ゆったり=9pt/16/1.15、標準=9pt/14/1.05、ぎっしり=8pt/12/1.0。利用者の「もっと詰めて／ゆったり」「1ページ◯字」「フォント◯pt余白◯mm」に合わせて再ビルドする。

## 出典・引用ルール（必須）
- 図表・本文・参考文献のすべてに**出典を明記**する。
- **ネット上の記事・情報を参照した場合は、参照当時のURLと参照日を必ず記載する**（例：参考文献に `<https://…>` ＋「（URLは○年○月○日参照）」）。URLの無い出典は追記して埋める。
- 出典は web_search / web_fetch で**実在・数値を裏取り**してから記載（捏造URL・捏造出典は厳禁）。

## 図の可読性ルール（必須・人手確認）
図を生成したら、**書き出した画像を必ず目視し、次を満たすまで直す**：
1. **文字・記号が「線（折れ線・軸線・グリッド）」と重ならない**。人間は線に重なった文字を読めない。重なりを見つけたら必ず修正（ラベルを点の反対側＝線の無い方へ逃がす／余白へ出す）。
2. 文字どうし・文字と目盛りが重ならない。
3. 文字が画面外で**見切れない**（特に複数行の出典は下余白を十分に取る）。
4. 図中の日本語は**日本語対応フォント**で描く（豆腐防止）。
5. 図表には**出典**を表示（データ図＝出典明記＋画像内に焼き込み／借用画像＝出典・作者・ライセンス明記）。
6. **図・画像のサイズは利用者の指定どおり自由に変更できる**（説明＝キャプションも図に付いたまま追従する）。利用者が「幅70%」「8cm」「もっと大きく／小さく」等と言ったら、その通りに変える。
   - 実装：pandoc Markdownで `![キャプション（出典含む）](fig.png){width=70%}` または `{width=8cm}` と指定 → `\includegraphics[width=…]` に変換され、`\caption` は図に追従。既定は本文幅にフィット。
   - 相対指定（%）と絶対指定（cm/mm/pt）どちらも可。2枚並び等はそれぞれに幅指定。
